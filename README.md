# 💼 Portfólio Web — Danielli Martins

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma página de **Portfólio / Currículo Web**, criada com **HTML5**, com o objetivo de apresentar informações pessoais, habilidades, projetos desenvolvidos e formas de contato.

A página foi estruturada buscando aplicar conceitos de **HTML semântico**, organização de conteúdo, tabelas, links, imagens e formulários.

---

## 🎯 Objetivo

O objetivo principal é desenvolver uma página web limpa e organizada que apresente:

* Informações sobre o desenvolvedor;
* Habilidades e conhecimentos;
* Projetos realizados;
* Tecnologias utilizadas;
* Formas de contato;
* Um formulário para envio de mensagens.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **PHP** — conhecimento/aplicação em projetos
* **JavaScript** — em aprendizado
* **TinkerCad** — utilizado em projeto com Arduino

No portfólio, são apresentados conhecimentos em **HTML, CSS e JavaScript**, além de habilidades relacionadas à estruturação de páginas e formulários.

---

## 🧑‍💻 Sobre Mim

A página apresenta uma breve descrição do desenvolvedor:

> Sou estudante de Desenvolvimento de Sistemas no SENAI.

Também são apresentadas habilidades relacionadas ao desenvolvimento web, como:

* HTML5 Semântico;
* CSS3 e Responsividade;
* Formulários e Validação;
* Estruturação de Dados.

A imagem de perfil utilizada no projeto possui dimensões de **150 × 150 pixels**, conforme especificado no desafio.

---

## 🚀 Projetos

O portfólio apresenta uma tabela para organizar os projetos desenvolvidos, contendo as seguintes informações:

| Projeto                                 | Tecnologia | Status    |
| --------------------------------------- | ---------- | --------- |
| Produção de elevador utilizando Arduino | TinkerCad  | Concluído |
| Verificador de Maioridade               | PHP        | Concluído |
| Desafio                                 | HTML       | Concluído |

Cada projeto possui um link para acesso ao seu respectivo repositório.

---

## 📬 Entre em Contato

A página também possui uma seção destinada ao contato, contendo um formulário agrupado dentro de um `<fieldset>` com o título **"Dados do Contato"**.

O formulário possui:

* Campo para nome;
* Campo para e-mail;
* Seleção de assunto;
* Campo para mensagem;
* Botão **Enviar Mensagem**.

Entre as opções de assunto estão **Oportunidade de Trabalho** e **Oportunidade de Estudo**.
